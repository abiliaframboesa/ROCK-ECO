# Data dictionary

All rows are simulated. No measurements were collected in the field.

| Field | Type | Description |
|---|---|---|
| site_id | character | Synthetic site grouping |
| sample_id | character | Synthetic sample identifier |
| surface_temperature_c | numeric | Simulated stone-surface temperature in °C |
| relative_humidity_pct | numeric | Simulated relative humidity (%) |
| substrate_moisture_index | numeric | Unitless illustrative index |
| substrate_roughness_index | numeric | Unitless illustrative index |
| surface_pH | numeric | Simulated surface pH |
| shade_fraction | numeric | Simulated shade fraction (0–1) |
| x_local, y_local | numeric | Arbitrary local-grid coordinates |
| lichen_presence | integer | Simulated binary response (0/1) |
| lichen_cover_pct | numeric | Simulated percentage cover; zero when absent |
